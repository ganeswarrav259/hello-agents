## 本章怎么学

从一个真实但足够小的需求开始，定义最小功能和验收，再决定项目结构。先能复现一条主流程，再逐步扩展。

本学习区设定的目标：独立写需求、说明模块职责、管理配置与依赖、编写测试，并完成一次有证据的复盘。
