## 本章怎么学

先问“什么叫做好、怎样证明”，再学习指标和评估框架。记录样本、输入、版本、评价方法与失败例子。

本学习区设定的目标：为一个小任务定义验收；区分示例成功与系统性评估；知道性能、质量与成本应分别记录。

## 第一项小任务

为之前的小程序设计三个正常输入、一个边界输入和一个失败输入；先写预期，再运行，不根据输出倒改验收标准。

当前只建立学习骨架；没有生成评测分数或声称任何模型更好。
