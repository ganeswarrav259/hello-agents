## 本章怎么学

先读原文一个小节，再用自己的话说明智能体想解决的问题、得到的输入和做出的行动；随后结合实际代码看数据从哪里来、到哪里去。

本学习区设定的目标：分清模型、程序和智能体；认识输入、状态、行动与反馈；能画一个简单执行流程。

[知识笔记](notes.md) 保存解释与复习；[问题记录](questions.md) 保存真实提问与验证；[代码与实践](practice/README.md) 保存以后产生的案例。

## 第一项小任务

读完开头相关小节后，选择一个日常任务，用自己的话写出输入、程序要做的事情、输出和可能失败的位置。先描述，不调用外部服务。

当前只建立学习骨架，不代表已经读完或掌握本章。
