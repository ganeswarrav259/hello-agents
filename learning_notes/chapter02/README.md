## 本章怎么学

先沿原文理解发展脉络，不先死记年份。重点记录每种方法想解决什么问题、依赖什么假设、还留下什么限制。

本学习区设定的目标：整理从符号方法到语言模型驱动方法的变化；区分历史事实、作者观点与自己的总结。

## 第一项小任务

阅读后做一个对照：挑两种方法，各写一句优势、限制及适合的问题，并标出原文位置。未核实的历史信息不要当作结论。

当前只建立学习骨架；进度以实际阅读和复述为准。
