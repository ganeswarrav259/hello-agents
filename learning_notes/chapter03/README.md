## 本章怎么学

按原文小节理解模型基础、提示与能力边界。遇到数学或结构图，先明确输入、输出和变量含义，再逐步深入。

本学习区设定的目标：认识 Transformer 相关基本概念；区分训练与调用；理解提示及回答需要验证的地方。具体模型或接口信息在真正使用时重新核对。
