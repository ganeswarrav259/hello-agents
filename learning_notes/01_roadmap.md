# 学习路线：边读、边做、边记录

[返回总目录](README.md)

这是一条按理解程度推进的路线，不设置虚假的完成日期，也不要求先背完全部 Python 语法。

| 阶段 | 对应内容 | 建议产出 | 进入下一阶段前检查 |
| --- | --- | --- | --- |
| 准备 | 环境、终端、文件路径、Git 最小流程 | 环境记录与一个离线 Python 输出 | 知道代码放哪里、命令在哪里执行 |
| 认识整体 | 前言、第 1—3 章 | 用自己的话解释概念、画简单流程 | 能分清模型调用、工具调用和程序执行 |
| 第一次动手 | 第 4 章 | 先离线拆解客户端，再学习三种范式 | 能解释类、消息列表、循环、返回值 |
| 比较与封装 | 第 5—7 章 | 一个低代码流程、一个框架案例、一个小模块 | 讲清入口、状态、接口和依赖方向 |
| 按需扩展 | 第 8—12 章 | 小规模记忆/检索/协议/评估实验 | 有输入、输出、失败案例和验证依据 |
| 综合实践 | 第 13—15 章 | 选一个项目先跑最小链路 | 能定位配置、业务逻辑和外部服务边界 |
| 独立完成 | 第 16 章 | 需求、结构、实现、测试、复盘 | 别人按 README 能复现核心功能 |

正文编号保持不变。第 11 章涉及训练时，先理解流程，再根据实际设备和预算决定是否运行；不把购买 GPU 或云服务作为入门前置要求。
扩展篇按问题选读，不要求在正文前全部完成。

## 每次学习的小循环

读一个小节 → 发来一小段代码或一个问题 → 解释本轮最重要的 1—3 个知识点 → 自己改一个地方 → 验证结果 → 归档到本章。

遇到不懂的 Python 语法，先做不联网的最小示例，再回到教程原代码。不要一次安装全书所有框架和依赖。

## 本次准备后的第一步

打开 [准备指南](00_preparation/README.md)，完成一次离线输出。
之后从第 1 章开始；前期第 4 章的代码讨论保留为预习材料，不据此判定第 1—3 章已经学会。
