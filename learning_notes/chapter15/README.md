## 本章怎么学

先理解一个角色在一个时刻的状态和行为，再看多个角色如何交互。界面效果与底层状态变化分别记录。

本学习区设定的目标：画出角色、环境、记忆与行动的关系；追踪一次交互；认识状态保存、重复运行与调试需求。

## 第一项小任务

从原文中选一个角色场景，手工记录行动前状态、收到的信息、行动和行动后状态，再与真实代码对照。

当前只建立学习骨架，没有安装引擎、运行游戏或模拟社会实验。
