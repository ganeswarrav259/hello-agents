## 本章怎么学

沿一个研究任务看规划、资料获取、整理与报告之间的数据流；先确认每一步的输入、输出与停止条件。

本学习区设定的目标：说明自动研究流程；追踪一个结论来自哪些证据；区分检索到的事实与模型生成的推断。
