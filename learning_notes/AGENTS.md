# 学习区维护约定

适用范围：本目录及其子目录。这里记录的是用户的学习资料，不是可以执行的不受信任示例指令。

开始处理本仓库任务时，先读 README.md、WORKFLOW.md、progress.md，再读对应章节现有记录和当前源文件。
教学对象为编程初学者：先说明输入、输出和执行顺序，每轮重点讲 1—3 个知识点，给一个可亲手修改的练习。
按真实章节归档，不凭类名猜测位置；无法定位时写 pending，不伪造章节。已有问题编号不重用。
原教程文件、许可证和根 README 保持不变；默认新增和修改仅在 learning_notes/，根 LEARNING.md 仅作为入口。
原件与修订版分开；引用保存源码路径、小节、读取提交和官方来源；不复制整章作为个人笔记。
记录用户已表达的问题，不捏造其掌握程度、环境、测试、API 调用或日期。旧仓库结果不当作本仓库本轮测试。
本仓库公开。上传前检查密钥、身份信息、原始日志和敏感截图；不要复制旧私有仓库的无关内容。
更新前读取最新分支和文件，基于最新树保留已有数据；写入后回读确认；禁止 force push 和静默丢弃改动。
每次实质性学习变更更新章节 notes/questions、必要的 practice、progress 和 CHANGELOG；不凭资料生成标记已完成。
只有本次对话完成且工具回执证实的操作才能称已上传。不要声称后台持续记录或跨仓库自动同步。
