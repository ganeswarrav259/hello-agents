## 本章怎么学

围绕原文中的 MCP、A2A、ANP 等内容，先看通信双方和消息，再看协议名称与实现。协议规范和 SDK 版本在实际使用时重新核对。

本学习区设定的目标：描述一次请求的发送方、接收方、格式与错误；区分协议规定和具体库的封装；认识权限与信任边界。
