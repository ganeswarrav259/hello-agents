## 每份实践至少交代

输入和目标；对应教材小节 / 问题编号；Python 与依赖版本；命令运行的工作目录；完整运行命令；预期输出；实际输出；失败和限制；一个学习者亲手完成的小改动。

先尝试不联网的最小示例，再连接外部服务。涉及模型、搜索、数据库或云资源时，明确数据发送目的地、费用和权限；不自动执行模型返回的代码。

原文 `code/` 下的代码不直接覆盖。若从教程复制，记录来源路径和提交版本，保留原有署名及许可信息。原始代码中的密钥必须替换为占位值，并说明做过脱敏。
