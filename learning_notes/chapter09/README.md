## 本章怎么学

从一个具体任务出发，观察程序给模型提供了哪些信息、如何组织、何时保留或删减。先理解数据，再讨论优化。

本学习区设定的目标：说明提示与上下文在实际案例中的关系；记录信息筛选的理由；设计可比较的输入和验收，而不是只凭回答长短判断效果。

## 第一项小任务

对同一个自造任务写两种上下文组织方式，先记录各自包含的信息与预期影响，再决定是否做真实调用对比。
