# 学习交接模板

[当前交接](../HANDOFF.md) · [提问提示词](../PROMPTS.md)

用于更新 learning_notes/HANDOFF.md，不必每次新建一份。历史保留在章节问题记录和 Git 提交中。这里只写恢复学习所需的摘要，不复制整段聊天。

```markdown
# 当前学习交接

## 基本信息
更新日期：
目标仓库 / 分支 / 笔记目录：
本轮读取基线 SHA：（不是更新后的最新 SHA）
学习目标和教学偏好：

## 当前进度
章节 / 小节 / 问题编号：
已经讲解的内容：
学习者已独立完成的内容与证据：
尚未验证或尚未掌握的内容：

## 环境与代码
系统 / Python / 关键依赖版本：（只填已确认内容）
原始代码、修订版、练习和测试的真实路径：
实际运行命令、结果、执行者和环境：
未提交的改动或无法访问的文件：（明确未知）

## 未解决事项
问题、阻塞和已经尝试的方法：
下一次只做哪一个最小动作：
恢复学习必须读取的文件：

## 维护边界
允许写入的范围与当次限制：
需要保留的原件、编号和来源：
敏感信息已脱敏；写入状态以实际工具回执为准。
```

示例：写“已解释 self，等待学习者独立改写”而不是“已掌握面向对象”；写“预期输出为你好，未运行”而不是“测试通过”。
本文件无法预先包含自身最终提交的 SHA；读者通过 Git 历史或聊天中的成功提交回执查最终提交，不把读取基线误认为最新版本。
