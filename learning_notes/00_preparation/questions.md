## PREP-Q001 · 新聊天交接与日常提问

**问题原意：** 学习者准备继续使用 Hello-Agents 仓库，希望换聊天时接得上，并知道每次发代码、报错或项目问题该怎样提问。
**本次处理范围：** 按“新开聊天，继续同一个 GitHub 仓库”设计；不新建仓库，不转移私人聊天。

**核心方法：** 固定规则放 AGENTS.md / WORKFLOW.md，当前状态放 HANDOFF.md，本轮任务用短提示词补充。开场读档、过程中讲解与归档、收尾更新摘要。

**交接内容：** 仓库与分支、学习目标、当前章节、已有讲解、独立完成的证据、未解决问题、真实文件路径、必要环境、一个下一步、允许修改的范围。未知项明确写待确认。
**日常提问：** 提供“章节或代码 + 不懂的位置 + 希望达到的目标”；报错问题额外附运行命令、工作目录和脱敏的完整报错。信息不全不妨碍先解释已知部分。

**产出：** [当前交接](../HANDOFF.md)、[8 类使用场景与提示词](../PROMPTS.md)、[可复用交接模板](../templates/handoff.md)。根 LEARNING.md 增加入口，学习维护约定增加交接规则。
**修改理由：** 减少新聊天重复背景；保留已讲解与已验证的区别；避免新助手重复初始化、写错仓库或覆盖既有笔记。

**验证范围：** 编写前通过 GitHub 读取了最新 main、维护约定、协作流程、进度、导航、变更记录及 CH04-Q001。本轮只修改文档，没有运行教材代码或真实模型接口。实际新聊天能否读取和继续，待当次工具结果验证；上传是否成功以提交回执为准。

**练习：** 在新聊天发送 PROMPTS.md 的开场模板，把最后一行改成“请检查 CH04-Q001 的待办，再从学习准备继续”。检查接手者是否说清“已讲解但未独立验证”，并能指出实际读取的提交和文件。
**通过依据：** 新聊天实际读到最新交接和对应记录，并在不重新初始化的情况下继续一个具体问题；不能仅凭模型说“我记住了”判定通过。

**来源：** 本仓库 WORKFLOW.md、progress.md、chapter04/questions.md；ChatGPT 项目功能说明见 PROMPTS.md 的官方来源。
