## 本章怎么学

作为综合项目，先看入口、运行说明和外部依赖，选一条最短功能链路，再深入多智能体协作及服务连接。

本学习区设定的目标：画出一次请求经过的模块；区分界面、业务逻辑和外部服务；能解释配置及失败处理。
