## 本章怎么学

跟踪一条信息从写入到检索、再到生成回答的路径。遇到存储和检索组件，先弄清输入输出，再考虑部署。

本学习区设定的目标：区分消息历史、记忆与检索结果在具体代码中的作用；理解 RAG 和存储的边界；观察检索失败情况。

## 第一项小任务

准备三条无隐私的自造文本和一个问题，先用手工方式选出相关信息，再对照程序如何完成同一过程。

当前只建立学习骨架；没有上传私人数据、建立数据库或运行检索服务。
