## 本章怎么学

围绕原文中的 Coze、Dify、n8n，先理解流程的输入、节点和输出，再学习实际操作。页面、功能和费用可能变化，操作时核对，不把旧截图当当前保证。

本学习区设定的目标：能画一个工作流；解释节点间传递的数据；定位失败发生在哪个节点，而不是只记录点击步骤。
