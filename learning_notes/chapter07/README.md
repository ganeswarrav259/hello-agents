## 本章怎么学

从一个最小入口看代码职责，再根据实际复用和测试需求理解接口、类与模块拆分。不把文件夹数量当作架构水平。

本学习区设定的目标：画出入口、模型调用、工具和状态之间的关系；解释依赖方向；对一个改动写出测试和取舍。

## 第一项小任务

挑一个真实类或函数，写出“谁调用它、它需要什么、它返回什么、为什么放在这个模块”。不知道的部分明确标记待确认。
