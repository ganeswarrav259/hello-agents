## 本章怎么学

先选原文中的一个框架案例，找入口与关键对象；沿一次调用梳理状态变化，再比较不同框架的抽象方式。不要一次背完所有 API。

本学习区设定的目标：区分自己写的逻辑与框架提供的能力；解释消息/状态如何流动；为实际案例记录依赖版本。

## 第一项小任务

在一个实际案例中标出“程序从哪里开始、调用哪个对象、返回什么”。先读源码和依赖说明，再准备对应环境。

当前只建立学习骨架；没有对任何框架安装、当前接口或多框架兼容作验证承诺。
